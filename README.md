## Overview

Diaspora Museum is a web application that allows users to explore museum galleries, view exhibitions and content, access documentation, learn about cultural heritage collections, browse curator and content information, book their own gallery visits, and interact with the platform through an easy-to-use interface.

As a Frontend Developer, I was responsible for designing and developing the complete user interface using React, TypeScript, Vite, and Tailwind CSS. My work focused on building responsive pages, implementing client-side routing, creating reusable UI components, and ensuring a consistent user experience across the application.

## My process

### Built with

Frontend Responsibilities

- Developed responsive and mobile-friendly user interfaces.
- Implemented application routing using React Router.
- Built reusable and maintainable React components.
- Created authentication screens including Sign Up, Login, Forget Password, and Password Reset flows.
- Developed gallery and content-related pages for users to explore museum content.
- Implemented profile management and user interaction pages.
- Built admin dashboard interfaces for managing users, subscriptions, and content.
- Maintained clean project structure and component-based architecture.
- Styled the application using Tailwind CSS for consistency and scalability.
